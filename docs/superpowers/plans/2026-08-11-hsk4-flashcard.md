# HSK 4 Flashcard Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a Vercel-deployable TanStack Start app for studying the 1,000 words introduced in the latest published HSK 3.0 Level 4 syllabus, with Indonesian and English glosses and an admin-only manual vocabulary workflow.

**Architecture:** TanStack Start owns file-based routes, SSR, and typed server functions; a TanStack Start/Nitro Vercel build runs the same monolith as Vercel Functions. Drizzle talks to Turso/libSQL for persistent vocabulary. Public selection and flashcard order are per-tab session state; server functions own database reads, administrator authentication, and all mutations.

**Tech Stack:** TypeScript, React, TanStack Start, TanStack Router, Vite/Nitro, Tailwind CSS, shadcn/ui (Radix), Drizzle ORM, `@libsql/client`, Turso, Zod, Vitest, Testing Library, Playwright, Vercel.

## Global Constraints

- Use `npx shadcn@latest init -t start --base radix --yes` to scaffold the TanStack Start + shadcn/ui project in this repository.
- Run Node.js 20 or later and npm; commit `package-lock.json`.
- Use the latest published HSK 3.0 Level 4 source list only: exactly 1,000 HSK 4-introduced entries, excluding HSK 1–3.
- Keep `data/hsk4-3.0.csv` as the committed canonical seed input and preserve source URL, version, and verification date per official row.
- Use CC-CEDICT only as the traceable English dictionary source; preserve CC BY-SA 4.0 attribution and share-alike notice in the repository and UI.
- Do not place any secret in a `VITE_` variable, source file, fixture committed to Git, or browser bundle.
- Use `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`, `ADMIN_PASSWORD`, and `ADMIN_SESSION_SECRET` only in server-side code.
- Use parameterized Drizzle queries; every admin mutation must call `requireAdmin()` in its server-function handler.
- Sort by a pinyin key that ignores case, spaces, and tone marks; use Hanzi as a stable tie-breaker.
- Preserve the approved “Meja belajar” direction: measured typographic hierarchy, restrained surfaces, no dashboard KPI grids, gradients, mascots, or decorative AI-style imagery.
- Treat `.superpowers/` and `.env*` as ignored local artifacts; never commit them.
